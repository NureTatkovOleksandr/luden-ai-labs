# Майбутні тести ЛР 1

Усі описані нижче продуктові TC — NOT RUN. Це не результати UX Figma F-T01–F-T07 і не перенесений PASS із симуляції. Фікстури: синтетичні User A/B/Admin C, Product X/Y, контрольовані Paid/Completed/неоплачені Bill та fake/sandbox результат провайдера. Для негативних мутацій перевірити snapshot до/після, для UI — DOM, фактичну навігацію і мережевий spy.

## Технічні уточнення й наскрізні сценарії

Їхні очікування можуть бути сильнішими за початковий AC. Посилання EXT/BR нижче явно відокремлює таке розширення; воно не входить до тексту оригінальних 33 AC автоматично.
