# Покриття й знаменники

1. Відновлення джерельного інвентаря: **33/33 = 100%**, 8/8 US. Одиниця — ID з першого Input Pack @822a688; точний текст кожного перевірено, пізніші редакції зіставлено. Це не прийняття P-рішень.
2. Простежуваність початкових AC: **33/33 = 100%** мають SRC→US→AC→BR→Component/API→TC. Для UI-only AC API=NOT APPLICABLE і вказано реальний компонент. US-09 дає ще **2/2 проєктних AC**, окремо PROPOSED.
3. Метрика методички на рівні SRC: підтверджений вихідний ланцюжок з наявними US/AC — **5/6=83.3%**; для SRC-06 немає вихідної Admin-US. Після включення запропонованої US-09 — **6/6=100% кандидатної специфікації**, а не погодженої реалізації. Командне review підтверджено, прийняття US-09/P-рішень окремо не заявлено.
4. Продуктові виконання: **0/56 = 0%**, одиниця — ID TC:35 на AC (33+2) +17 наскрізних +4 NFR. Усі NOT RUN. Figma PASS із UX QA не є пройденим продуктовим тестом. Code coverage не вимірювалось.
5. CSV має **64 рядків**, але повторні SRC/AC/TC не збільшують унікальні знаменники. EXT-01–10 — збережені запропоновані технічні уточнення; вони не збільшують число початкових AC. SRC-07 та F-функції виключені, їх тест NOT DEFINED.
